Key Technical Decisions That Matter

Deep Technical
  • 📦 Why esbuild over Webpack/Rollup? — 10-100x faster build times (31 seconds for entire server). Zero config needed. Perfect for serverless where cold start = bundle load time.
  • 🔄 Lazy Prisma Loading: require("@prisma/client") at top level = crash if Prisma binary not generated. Dynamic require() in a function = load on first use. Critical for Vercel's ephemeral filesystem.
  • 🛡️ import.meta.url Fallback: ESM uses import.meta.url for __dirname. But Vercel bundles to CJS where it's undefined. Added try-catch with process.cwd() fallback in 3 files.
  • 📤 /tmp for File Uploads: Vercel serverless has read-only filesystem except /tmp. Multer upload path defaults to /tmp/cc-uploads — ephemeral but functional.
  • 🔐 JWT + CORS + Rate Limiting: Three layers of security. JWT for stateless auth, CORS to prevent cross-origin attacks, rate limiting to prevent abuse.
  • 🤖 Triple AI Provider Fallback: NVIDIA primary → Gemini secondary → Groq tertiary. If one API is down or rate-limited, automatic fallback. Zero downtime for AI features.
